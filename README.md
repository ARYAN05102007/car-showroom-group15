**Group 15 | Assigned Project #43**

A showroom page that displays car models with their specifications and lets you compare 2 to 3 cars side by side.

## Features

- Car cards with image, model name and a specs table
- "Compare" checkbox on every car
- Select up to 3 cars (a warning shows if you try a 4th)
- Comparison table is built dynamically with JavaScript
- Dark theme, card grid layout and a highlighted comparison section
- "Clear selection" button

## How to run

1. Download or clone this repository.
2. Open `index.html` in any browser. No installation needed.

## Files

- `index.html` - page structure
- `style.css` - dark theme and layout
- `script.js` - car data (array), checkbox handling and comparison table
- `images/` - placeholder car pictures (replace with real photos if you like)

Built with only HTML, CSS and basic JavaScript (no libraries).
