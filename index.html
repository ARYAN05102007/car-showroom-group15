About this showroom

Car Showroom is our Semester 1 web development project (Group 15, Project 43). It shows six popular cars with their key specifications and lets you compare them in a single table.

Made by Aman Babu, Ashish Gupta and Aryan using only HTML, CSS and basic JavaScript.
